## محتوا از سرور می‌آید
- از این به بعد نکات و تست‌های کنکوری از سرور (پنل ادمین) بارگذاری می‌شوند و در AsyncStorage کش می‌شوند؛ فایل‌های TS داخل این پوشه فقط «seed» و محتوای آفلاین (fallback) هستند.
- برای انتقال محتوای فعلی به سرور: `npx tsx scripts/export-konkur.ts --figure-base-url=/uploads/konkur` و سپس فایل `konkur-export.json` را به `POST /admin/konkur/import` بدهید (عکس‌های `figures/` باید قبلاً آپلود شوند).
- برای محتوای تازه، از پنل ادمین اضافه کنید؛ نیازی به انتشار نسخه‌ی جدید اپ نیست.

## به‌روزرسانی seed سرور («محتوای آماده‌ی اپ»)
هر بار محتوای bundle‌شده‌ی اپ (`src/content/konkur/*.ts` یا `figures/`) عوض شد، seed داخل API باید دوباره ساخته شود:
1. `cd mobile/MathMotion && npx tsx scripts/export-konkur.ts --figure-base-url=/uploads/konkur --out=../../backend/go-api/internal/service/konkur/seed/konkur-seed.json`
2. کپی تصویرها: `cp src/content/konkur/figures/*.png ../../backend/go-api/internal/service/konkur/seed/figures/`
3. ایمیج API را دوباره build و deploy کن (seed با `go:embed` داخل ایمیج است، پس بدون rebuild عوض نمی‌شود).
4. در پنل ادمین، تب کنکور، کارت «محتوای آماده‌ی اپ» → «بارگذاری محتوای اولیه روی سرور». فقط موارد جدید اضافه می‌شوند و ویرایش‌های دستی دست نمی‌خورند.
